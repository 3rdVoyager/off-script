How to set up OffScript! and practice your lines.

Getting started

  1. Add a script

    Upload or paste your script JSON in Settings.

  2. Choose practice characters and scenes

    Pick who you are learning and which scenes to include. Practice tools only show lines for those characters.

  3. Try Reveal

    Read the cue, remember your line, then reveal it. Use the arrow keys to move between lines.

  4. Try First Letter or Type

    Type your lines with help (First Letter) or from memory (Type).

  5. Review your progress

    See mastery by character and scene on the Progress page.

Your data

Scripts, settings, and progress are stored in this browser. Sign-in and cloud sync may be added later; for now, clearing site data will remove your scripts and progress.
